# Práticas de Algoritmos com Laço While (PA-While) 🔄💻

Repositório dedicado ao estudo, prática e desenvolvimento de algoritmos e lógica de programação utilizando a estrutura de repetição **while** (enquanto), focando no controle de fluxo baseado em condições pré-estabelecidas.

---

## 🚀 Sobre o Projeto

Este projeto reúne exemplos práticos e exercícios para fixação de conceitos fundamentais da programação, demonstrando como utilizar o laço `while` para executar blocos de código repetidamente enquanto uma determinada condição for verdadeira.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem de Programação:** JavaScript / Lógica de Programação.
- **Conceitos Aplicados:** Estruturas de repetição condicional, controle de fluxo, prevenção de loops infinitos e lógica computacional.
